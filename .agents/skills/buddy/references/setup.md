# setup.md

> **Purpose**
>
> Bootstrap a new project or development environment following project standards.

## Objective

Create a clean, runnable, and maintainable foundation.

Do not implement business features.

---

## Checklist

Set up:

* Project structure
* Dependencies
* Configuration
* Environment variables
* Logging
* Database connection
* Docker (if applicable)
* Health check
* README

---

## Rules

* Follow project architecture.
* Use approved technology stack.
* Keep the setup minimal.
* Avoid unnecessary packages.
* Do not introduce premature abstractions.
* Ensure the project runs successfully.

---

## Deliver

Provide:

* Files created
* Dependencies installed
* Configuration completed
* Verification steps

---

## Success Criteria

The project builds successfully, starts without errors, and provides a stable foundation for future development.
