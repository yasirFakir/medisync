# test.md

> **Purpose**
>
> Verify that the implementation is correct, reliable, and does not introduce regressions.

## Objective

Test the implemented feature, not the entire project.

---

## Checklist

Verify:

* Functionality works as expected.
* Edge cases are handled.
* Invalid input is rejected.
* Errors are handled gracefully.
* Existing functionality still works.

---

## Test Types

When applicable:

* Unit Tests
* Integration Tests
* API Tests
* UI Tests
* AI/OCR validation (if relevant)

---

## Rules

* Test only the affected modules.
* Avoid unnecessary test generation.
* Prefer meaningful tests over high coverage.
* Never modify production code just to satisfy tests.

---

## Deliver

Report:

* Tests performed
* Results
* Failed cases
* Regression risks

---

## Success Criteria

The feature behaves correctly, existing functionality remains intact, and no critical regressions are introduced.
