# Android Builder & Compose Skill

## Design System Tokens
- **Primary Teal:** `#00685F`
- **Secondary Sky Blue (OCR / Data):** `#006492`
- **Safety Amber (Warnings / Urgent Triage):** `#825100` / `#F59E0B`
- **Emergency Crimson (Critical Triage):** `#BA1A1A`
- **Canvas / Background:** `#F9F9FF`
- **Typography:** Plus Jakarta Sans / Roboto

## Coding Standards
1. Use Material 3 Composables (`Scaffold`, `TopAppBar`, `NavigationBar`, `Card`, `AssistChip`).
2. Implement explicit Loading (`CircularProgressIndicator`), Empty, Error, and Success states.
3. Use Kotlin Coroutines & Flow for reactive state updates.
